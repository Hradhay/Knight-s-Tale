## About the Game

Knight's Tale is a 2D action RPG developed in Unity using C#. The project brings together player controls, combat, and interactions with the game world.

Building the game involved working on how the different parts of an action RPG fit together, from player input and movement to combat and gameplay feedback.

## Project Structure

```text
Knight-s-Tale/
├── Assets/
├── Packages/
├── ProjectSettings/
└── README.md
```

- `Assets` contains game scripts, scenes, graphics, audio, and other project assets.
- `Packages` contains the Unity package dependencies.
- `ProjectSettings` contains the project's Unity configuration.
- `README.md` contains the project description and setup instructions.

## Getting Started

1. Install Unity Hub and the Unity Editor version used by this project.
2. Clone or download this repository.
3. Open Unity Hub and select **Add project from disk**.
4. Select the folder containing `Assets`, `Packages`, and `ProjectSettings`.
5. Open the project and allow Unity to import assets and resolve packages.
6. Open the relevant game scene from the `Assets` folder and press **Play**.

You can check `ProjectSettings/ProjectVersion.txt` to find the Unity Editor version used by the project.
